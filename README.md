# TopClean Gebäudeservice

Responsive homepage demo for a Lübeck-based commercial cleaning business, built with the Next.js App Router, TypeScript, and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```

The hero photo in `public/images/hero-cleaning.jpg` is a generated visual created for this demo. Replace it with an approved company photograph before using the site as a live representation of TopClean's team or work.
